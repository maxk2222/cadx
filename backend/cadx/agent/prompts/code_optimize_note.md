TOPOLOGY OPTIMIZATION DOWNSTREAM: the part you generate is the DESIGN DOMAIN.
Build the FULL solid base part — do NOT hand-carve weight-reduction pockets,
lattices, lightening holes or skeletonized shapes to hit a volume/mass target.
Topology optimization runs later and needs solid material to remove; a
pre-thinned part leaves it nothing to work with. Preserved spec features
(mounting holes, seats, faces, keep regions) must still be modelled exactly.
