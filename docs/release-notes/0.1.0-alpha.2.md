# CADX 0.1.0-alpha.2

> **⚠️ Alpha release.** CADX is under heavy development — expect rough edges,
> changing interfaces and incomplete docs coverage. Self-host only;
> local, single-user deployment model. Feedback and bug reports welcome.

CADX is a local, LLM-driven CAD agent: images + text prompt in → verified,
parametric build123d code out — real manufacturing exports (STEP/STL/3MF/GLB),
not just a mesh. It runs entirely on your hardware: local LLM (LM Studio,
llama.cpp, vLLM) or an API provider, local mesh generation sidecar,
no telemetry, no cloud dependency.

**Second alpha.** The full eval pipeline (codegen → FEM → TopOpt → refine →
export) now passes end-to-end on a live Docker stack: the `robot_arm_mount`
case produces a single watertight body at ~50% volume fraction, verified
safety factor, load-path certificate, and all declared features re-cut and
measured at nominal diameter on the refined mesh.

## Platform matrix

| Platform | Status | Notes |
|---|---|---|
| macOS Apple Silicon (MLX) | ✅ verified | primary dev target |
| macOS Intel | ⚠️ untested | no GPU mesh acceleration |
| Linux + CUDA | ⚠️ untested | docker tier implemented, not yet validated |
| Linux + ROCm | ⚠️ untested | `HSA_OVERRIDE_GFX_VERSION` may be needed |
| Windows (WSL2) | ❌ untested | docker paths should port; not validated |
| Any / CPU-only | ⚠️ works | mesh generation falls back or uses `MESH_FAKE` |

## Install

```bash
curl -fsSL https://github.com/maxk2222/cadx/releases/download/v0.1.0-alpha.2/install.sh | bash
# or: install.sh --channel alpha --dir ~/cadx
```

Requirements: bash ≥3.2, curl, python3 ≥3.11, git, docker + compose.
First install takes **10–20 min** (image builds + deps).

## Highlights

- Round keep prisms + `pad_dia` boss detection: TopOpt no longer eats the
  boss or pastes rectangular pads around bores — keep regions restore as
  cylinders and every declared hole comes back round on the final mesh.
- Deterministic load-case anchor rebinding: hallucinated `hole_index`
  references are rebound to the correct anchors; `g_load` binds to `all`,
  broad fixtures rebind to mount holes, moments rebind to threaded anchors.
- Refine verify FEM now anchors regions on the refined mesh itself
  (bore regions bind by axis+dia+center hint), and the rim-fit detector
  interpolates the 50%-blocked ring crossing — measured bore diameters now
  match the declared nominal within tolerance even beside occluding bosses.
- Queue-side refine budget counts exec-class feature finishing; the FEM
  case-solve fork pool is timeout-bounded with serial fallback.

## Known limitations

- Verified on macOS (Apple Silicon, MLX) only — Linux/Windows GPU tiers are
  untested; CPU tier works everywhere Docker does.
- Requires a local LLM backend (LM Studio / llama.cpp / vLLM) or an API
  provider key for generation; no bundled model weights.
- Alpha quality: interfaces, eval suites and settings keys may still change.
